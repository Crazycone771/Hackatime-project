This is a space shooter game, which uses a lot of complicated codes to use the space shooter. Basically, it is like an extension like other games, where the arrow keys are the controls, where space is shoot the targets, it has powerups and other stuff.
another way you could try ths is using the link provided below
https://spaceblasterfinaledition.netlify.app
i made it using python, came up with the idea from a youtube video i was watching, talking about shooter games, and that time i was still thinking about what to make, and then came across an old game of space shooter, looked cool, and i wanted to recreate it, so i used the python coding systems that i had learned in game design in school, and made it alongside learning from tutorials and asking my brothers and teachers about how to make it better, and eventually made it the final edition of space blaster.
at first, i added the map with stars, drawing the stars using the command canvas on python, so it looks like the ship is moving through space. after that i added the powerups to help with the game, because dodging everything with nothing to help you got impossible fast. then came the waves and bosses, and added progressively harder waves, so every wave there is more enemies and they get faster and stronger, and every few waves a boss shows up with way more health. i used cooldowns too so you cant just spam the shoot button and hold it forever, you actually have to time your shots. i used tkinter so it actually worked as a real game with a window, and canvas for drawing everything on the screen.
when i first let my friends play it they said it was too easy, so i made it one hit, one hit and your gone. that one change made the whole game harder and better, because now the powerups and shields actually save you, where before you could just tank through everything and not care. the shields block a hit for a few seconds so you use them when you really need them, not just whenever.
after all of that i skipped through versions testing each one, fixed bugs like enemies stacking on top of each other, and kept getting people to try it until it felt right, and that's how it became the final edition of space blaster. But another problem I am going to fix is the shield from shop, as it does not allow the player to be killed, making it impossible to die.
